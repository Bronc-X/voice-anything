# 来源与本次变更

macOS 公共代码基线：`HD838A/remote-mic-app`，提交 `838db98b781a7039347158a0eda838e5c639910d`（2026-09-21）。Windows 来源为此前本地开发的 WPF/.NET RC003MS 版本。原项目和原安装目录保留不变。

GitHub 已有官方 [GetSayAll/remote-mic-app-windows](https://github.com/GetSayAll/remote-mic-app-windows)，以及其他 Windows 移植项目。本项目不宣称是首个 Windows 版本，也不代表 SayAll 官方。

| 范围 | 原 Windows 版 | 本次工作 |
| --- | --- | --- |
| 使用统计 | 无按日/周统计界面 | 新增真实按键计数、音频秒数、会话数，跨午夜拆分时长 |
| 回眸 | 无转写归档与搜索 | 默认关闭的本地新增文字捕获、搜索、应用/日期筛选、分页、导出、删除 |
| MCP | 无 | 两端共用的只读 stdio Helper，独立客户端授权与撤销 |
| 设备身份 | 物理蓝牙身份写死，音频可能选第一个服务 | 用户选择实际设备；HID 与 ATVV 绑定到同一身份；切换设备取消旧桥接 |
| 硬件界面 | RC003 外形与按键固化在界面 | 共享型号文件、外形图、归一化热点、自定义控件 ID、手势限制、型号包导入 |
| 按键映射 | 单一配置 | Windows 按型号保存；macOS 接入原有按设备配置 |
| macOS | 原公开版已有统计、回眸、MCP 和原生硬件链路 | 增加共享数据格式、同一 MCP Helper、新的原生页面与型号配置读取；原生构建仍待验收 |

macOS 上游还有 RC001、电量、更多系统动作等能力；两端目前尚未做到所有上游功能逐项相同。Siri Remote、手机/手表、部分宏与商业功能依赖上游可选私有包，不属于本版本已交付能力。完整功能一致性以 [ACCEPTANCE.md](ACCEPTANCE.md) 的实测结果为准。

保留了 Windows 的输入法选择、按住说话、临时麦克风切换与恢复、试听与声谱、Codex/Claude Code 动作模板和后台桥接。驱动文件、机器码与 Gadget 指纹校验继续保留。
