# 本地数据与 MCP

回眸与 Agent 访问默认关闭。统计保存在本机，不上传分析服务。Voice Anything 负责接入硬件并触发所选输入法；输入法自身的数据处理取决于它的设置。

Windows 数据位于 `%LOCALAPPDATA%/VoiceAnything`，macOS 数据位于 `~/Library/Application Support/VoiceAnything`。`journal.json` 保存每日统计、回眸和授权摘要。记录使用原子替换写入，读取失败会显示错误，不会静默清空文件。请自行按需要备份此目录。

回眸只保存一次语音会话的新增文字、应用名称、型号和时间。Windows 使用公开 UI Automation，拒绝密码框、失焦、手动键入和无法确定边界的变化；macOS 复用公开辅助功能捕获链路。输入框不支持或无法可靠提取时，不保存本次记录。原始上下文不写入回眸。Windows 的本地试听录音仅在录音测试页面生成。

## Agent 授权

在“统计 · 回眸 · Agent”开启本地 Agent 访问，为每个客户端生成一次连接配置。令牌只显示一次，文件中保存 SHA-256 摘要。MCP Helper 使用 stdio，不监听网络端口；每次读取都会重新检查开关与授权。关闭总开关或撤销客户端，对已有连接同样生效。

| 工具 | 可读取的内容 |
| --- | --- |
| `search_reflections` | 按关键词、应用、日期检索，支持分页 |
| `get_reflection` | 指定 UUID 的回眸 |
| `list_applications` | 回眸中出现过的应用 |
| `get_usage` | 指定日期范围内的每日按键、收到的音频秒数和会话数 |

两个平台打包同一份 MCP Helper，协议版本为 `2025-06-18`。搜索限制每页 100 条；回眸最多 10,000 条，单条最多 32,768 个 UTF-16 字符，本地文件上限 64 MB。达到上限会提示先导出、删除记录。

示例连接配置由应用生成，包含本机可执行文件路径和 `VOICE_ANYTHING_MCP_TOKEN` 环境变量。不要把真实配置复制进 README、Issue 或版本库。转写文本是数据，客户端不应把其中的内容当成工具指令。

第三方 Agent 可能把读取内容发送到其云端模型。MCP 令牌限制的是本接口的访问；它不是磁盘加密，也不能阻止已经拥有同一系统账户文件权限的其他程序直接访问数据目录。
